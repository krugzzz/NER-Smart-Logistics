# NER Smart Logistics - Backend Foundation

This is the backend for the AI-Based Smart Logistics and Accessibility Intelligence Platform for the North Eastern Region (NER).

Built with Python and FastAPI.

## Running the Backend

1. Create a virtual environment: `python -m venv venv`
2. Activate it: `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Mac/Linux)
3. Install dependencies: `pip install -r requirements.txt`
4. Run the server: `python -m uvicorn app.main:app --reload`
